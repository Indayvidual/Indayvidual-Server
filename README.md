# Indayvidual (인데이비주얼)
> **Indayvidual**은 **Day + Individual**의 합성어로,  
개인의 라이프스타일에 맞춘 맞춤형 일정 관리 솔루션입니다.  
여러 앱을 오가며 일정을 관리하는 불편함을 해소하고, 필요한 기능만 선택해 사용할 수 있는 통합 생산성 플랫폼을 제공합니다.

## 🚀 주요 기능

### 1. 생산성 기능 통합
- 캘린더 + 투두 리스트 + 시간표 통합 관리
- 여러 앱을 사용하는 번거로움 감소
- 일정 관리 효율성 향상

### 2. 기능 커스터마이징
- 메모장, 가계부, 해빗 트래커 중 필요한 기능만 선택 가능
- 불필요한 기능 사용 방지로 집중도 향상
- 개인 맞춤형 사용 경험 제공

### 3. 편리한 위젯 제공
- 월간 이동 및 일정 확인 가능
- 앱 진입 없이도 일정 확인 가능
- 확인 과정에서의 스트레스 감소
